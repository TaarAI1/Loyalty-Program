## Brand core

| Token | Hex | Usage |
| --- | --- | --- |
| Deep navy | `#000820` | Sidebar, dark panels, primary text |
| Navy secondary | `#001020` | Gradients |
| Logo lime (primary CTA) | `#B9EB32` | Buttons, active nav, accents, logo `+` |
| Logo lime hover | `#A6D42A` | Button hover |
| Soft lime | `#D0F878` | Soft highlight (optional) |
| Lime wash | `#F4FCE3` | Soft lime surfaces |
| Warm white | `#F8F8F8` | Page background |
| Electric blue | `#88C8FF` | Glow / supporting text on navy |
| Muted blue | `#487898` | Labels, muted text, dividers |
| Nav inactive | `#C5D0DC` | Sidebar menu text |
| Nav icon muted | `#8FA3B8` | Sidebar icons |
| Field border | `#D0DCE6` | Inputs |
| Field fill | `#F5F7FA` | Input background |
